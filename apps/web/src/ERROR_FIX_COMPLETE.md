# 에러 수정 완료 가이드

## 수정된 에러들

### 1. ✅ GoTrueClient 중복 인스턴스 경고

**문제:**
```
Multiple GoTrueClient instances detected in the same browser context.
```

**원인:**
- `/lib/supabase.ts`와 `/utils/supabase/client.ts`에서 각각 Supabase 클라이언트 생성
- 싱글톤 패턴이 적용되지 않음

**해결:**
- `/lib/supabase.ts`에 싱글톤 패턴 적용
- `/utils/supabase/client.ts` 삭제
- 모든 파일에서 `/lib/supabase.ts`의 `supabase` 인스턴스 사용

**수정된 파일:**
- `/lib/supabase.ts` - 싱글톤 패턴 추가
- `/pages/JoongsanMatchesPage.tsx` - import 경로 변경
- `/lib/hooks/useServerScheduleMonitor.tsx` - import 경로 변경
- `/lib/hooks/useScheduleExecutor.tsx` - import 경로 변경
- `/utils/supabase/client.ts` - 삭제

### 2. ✅ React.forwardRef() 경고

**문제:**
```
Warning: Function components cannot be given refs. 
Check the render method of `SlotClone` at AlertDialogOverlay
```

**원인:**
- `AlertDialogOverlay` 컴포넌트가 ref를 받을 수 없는 함수형 컴포넌트

**해결:**
- `React.forwardRef()`로 컴포넌트 래핑
- `displayName` 설정

**수정된 파일:**
- `/components/ui/alert-dialog.tsx`

```tsx
const AlertDialogOverlay = React.forwardRef<
  React.ElementRef<typeof AlertDialogPrimitive.Overlay>,
  React.ComponentPropsWithoutRef<typeof AlertDialogPrimitive.Overlay>
>(({ className, ...props }, ref) => {
  return (
    <AlertDialogPrimitive.Overlay
      ref={ref}
      // ... props
    />
  );
});
AlertDialogOverlay.displayName = AlertDialogPrimitive.Overlay.displayName;
```

### 3. ✅ 템플릿 삭제 에러

**문제:**
```
Error: Cannot delete template. It is currently being used in schedules.
```

**원인:**
- 자동 생성된 경기 템플릿을 삭제하려고 할 때 관련 스케줄이 존재
- 수동으로 생성된 템플릿과 동일하게 처리됨

**해결:**
- 자동 생성 템플릿(`category: 'joongsan_match'` 또는 이름이 `[자동]`으로 시작) 판별
- 자동 생성 템플릿: 관련 스케줄도 함께 삭제
- 수동 생성 템플릿: 기존대로 삭제 불가 에러 반환

**수정된 파일:**
- `/supabase/functions/server/index.tsx` - DELETE /templates/:id

**로직:**
```typescript
const isAutoGeneratedMatch = template?.category === 'joongsan_match' || 
                             template?.name?.startsWith('[자동]');

if (schedules && schedules.length > 0) {
  if (isAutoGeneratedMatch) {
    // 관련 스케줄도 모두 삭제
    for (const schedule of schedules) {
      await supabase.from('schedules').delete().eq('id', schedule.id);
      // Audit log 기록
    }
  } else {
    // 수동 템플릿: 삭제 불가
    return c.json({ error: '...' }, 400);
  }
}
```

### 4. ✅ Import 경로 에러 (Vite)

**문제:**
```
Failed to resolve import "../../utils/supabase/client" from "lib/hooks/useServerScheduleMonitor.tsx"
Failed to resolve import "@/lib/utils/utils" from "components/ui/alert-dialog.tsx"
```

**원인:**
- 삭제된 `/utils/supabase/client.ts` 파일을 여전히 import
- `@/` alias 사용 (프로젝트에 alias 설정 없음)

**해결:**
- 모든 파일에서 `/lib/supabase.ts`로 import 경로 변경
- `@/lib/utils/utils` → `../../lib/utils/utils`로 상대 경로 변경

**수정된 파일:**
- `/lib/hooks/useServerScheduleMonitor.tsx`
- `/lib/hooks/useScheduleExecutor.tsx`
- `/components/ui/alert-dialog.tsx`
