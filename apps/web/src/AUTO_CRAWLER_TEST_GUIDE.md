# 자동 크롤링 시스템 테스트 가이드

## 🎯 목적

자동 크롤링 시스템이 정상적으로 동작하는지 즉시 확인하기 위한 테스트 가이드입니다.

---

## ⚡ 빠른 테스트 (5분 이내)

### 1단계: 현재 시간 확인

```
현재 시각이 14:30이라고 가정
```

### 2단계: 크롤링 시간 설정

1. **ADMIN 계정으로 로그인**
2. **Dashboard → 시스템 설정**
3. **"자동 크롤링 시간 설정" 패널 찾기**
4. **시간 입력**:
   - 시: `14` (현재 시각)
   - 분: `32` (현재 시각 + 2분)
5. **저장 버튼 클릭**
6. **페이지 새로고침** (F5)

### 3단계: 디버그 로그 열기

1. **화면 우측 플로팅 버튼 클릭** (로그 아이콘)
2. **필터에서 "AutoCrawler" 선택**

### 4단계: 대기 및 확인

1. **설정한 시간까지 대기** (최대 2분)
2. **디버그 로그 확인**:
   ```
   [AutoCrawler] 자동 크롤링 시작 (매일 06:00)
   [AutoCrawler] 자동 크롤링 성공
   ```
3. **성공 시 결과 확인**:
   - `total_parsed`: 파싱된 경기 수
   - `upserted`: 저장된 경기 수
   - `failed`: 실패 수

### 5단계: Audit Logs 확인

1. **Audit Logs 페이지로 이동**
2. **Event Type: "AUTO_CRAWL_SUCCESS" 검색**
3. **최신 로그 확인**:
   - 실행 시간
   - 크롤링된 경기 수
   - 상세 정보

## 📊 상세 테스트

### 테스트 1: 자동 크롤링 성공

**목표**: 정상적인 크롤링 실행 확인

**절차**:
1. 크롤링 시간을 현재 + 2분으로 설정
2. 새로고침 후 대기
3. 디버그 로그에서 성공 메시지 확인
4. Audit Logs에서 `AUTO_CRAWL_SUCCESS` 확인
5. 중산 경기 페이지에서 데이터 확인

**성공 기준**:
- ✅ 크롤링이 정확한 시간에 실행됨
- ✅ 경기 데이터가 저장됨
- ✅ Audit Log가 기록됨

---

### 테스트 2: 중복 실행 방지

**목표**: 같은 날짜에 두 번 실행되지 않는지 확인

**절차**:
1. 테스트 1 완료 후
2. 크롤링 시간을 현재 + 2분으로 다시 설정
3. 새로고침 후 대기
4. 디버그 로그 확인

**성공 기준**:
- ✅ 두 번째 실행이 스킵됨
- ✅ 디버그 로그에 실행 기록이 없음
- ✅ Audit Logs에 새 기록이 생성되지 않음

**참고**: 다음 날짜에는 정상 실행됩니다.

---

### 테스트 3: 경기 일정 자동 송출

**목표**: 크롤링된 경기가 전광판에 자동 송출되는지 확인

**사전 준비**:
- 크롤링으로 경기 데이터가 저장되어 있어야 함

**절차**:
1. **중산 경기 페이지**에서 오늘 경기 확인
2. 경기 시간 확인 (예: 09:00 ~ 11:00)
3. **시스템 시계를 조작하거나** 실제 경기 시작 10분 전 대기
4. **디버그 로그** 확인:
   ```
   [MatchScheduleSync] 템플릿이 업데이트되었습니다
   created: 1
   ```
5. **전광판 페이지** (`/display/view`)에서 경기 일정 표시 확인

**성공 기준**:
- ✅ 경기 시작 10분 전에 템플릿 자동 생성
- ✅ 전광판에 30초씩 표시
- ✅ 경기 종료 후 템플릿 자동 삭제

---

## 🔧 문제 해결

### 크롤링이 실행되지 않음

**확인 사항**:
1. ✅ 브라우저가 열려있는가?
2. ✅ 로그인 상태가 유지되는가?
3. ✅ 설정한 시간이 정확한가?
4. ✅ 페이지를 새로고침했는가?

**디버그**:
```
디버그 로그 → AutoCrawler 필터
→ "자동 크롤링 시스템 초기화" 메시지 확인
→ scheduled_time이 올바른지 확인
```

---

### 크롤링은 되지만 데이터가 없음

**원인**: 사이트에 오늘 경기 데이터가 없을 수 있음

**확인**:
1. https://e-soccer.gys.or.kr/ 접속
2. "오늘의 경기" 탭 → "중산" 탭 확인
3. 경기 데이터 존재 여부 확인

**해결**:
- 데이터가 있는 날짜에 다시 테스트
- 수동 크롤링으로 먼저 확인

---

### 경기 일정이 전광판에 표시되지 않음

**확인 사항**:
1. ✅ 크롤링이 성공했는가?
2. ✅ today_matches 테이블에 데이터가 있는가?
3. ✅ 현재 시간이 경기 시작 10분 전 ~ 종료 사이인가?

**디버그**:
```
디버그 로그 → MatchScheduleSync 필터
→ "Sync completed" 메시지 확인
→ templates_created 값 확인
```

## 💡 팁

### 즉시 테스트하기

현재 시간보다 1분 후로 설정하면 빠르게 테스트할 수 있습니다.

```
현재: 14:30
설정: 14:31 (1분 후)
대기: 1분
```

### 디버그 로그 활용

필터 기능을 활용하면 원하는 정보만 빠르게 확인할 수 있습니다.

```
- AutoCrawler: 크롤링 관련 로그만 표시
- MatchScheduleSync: 경기 동기화 로그만 표시
- error: 에러만 표시
```

### Audit Logs 검색

Event Type 필터로 특정 이벤트만 빠르게 찾을 수 있습니다.

```
- AUTO_CRAWL_SUCCESS: 성공한 크롤링
- AUTO_CRAWL_FAILED: 실패한 크롤링
- MATCH_TEMPLATE_AUTO_CREATED: 자동 생성된 템플릿
```
