# 스케줄 시간 설정 완전 가이드

## 📋 개요

스케줄 시스템은 **3가지 독립적인 시간 개념**을 사용합니다:
1. **시작 날짜/시간**: 스케줄이 처음 실행되는 시점
2. **스케줄 종료일**: 반복 스케줄이 끝나는 날짜 (선택사항)
3. **템플릿 표시 시간**: 한 번 실행될 때 화면에 표시되는 시간

---

## 1️⃣ 시작 날짜 및 시간 (start_datetime)

### 설명
- 스케줄이 **처음 실행되는 날짜와 시간**
- 반복 스케줄의 경우, 이 시간에 매일/매주 실행됨

### 예시
```
시작 날짜/시간: 2025-01-15 09:00
→ 1월 15일 오전 9시부터 시작
```

### 필수 여부
- ✅ **필수 입력**

---

## 2️⃣ 스케줄 종료일 (end_datetime)

### 설명
- **반복 스케줄이 언제까지 실행될지** 설정
- **반복 자체가 끝나는 날짜**
- 일회성 스케줄은 필요 없음 (한 번만 실행되므로)

### 예시
```
시작: 2025-01-15 09:00
종료: 2025-02-15 09:00
반복: 매일

→ 1월 15일부터 2월 15일까지 매일 오전 9시에 실행
→ 2월 15일 이후에는 더 이상 실행되지 않음
```

### 사용 사례

#### ✅ 반복 스케줄 + 종료일 설정
```
📅 매일 오전 9시에 운영 시간 안내
   시작: 2025-01-01 09:00
   종료: 2025-03-31 09:00
   반복: 매일
   
   → 1월 1일 ~ 3월 31일까지 매일 오전 9시 실행
```

#### ✅ 반복 스케줄 + 종료일 없음 (무기한)
```
📅 매일 오전 9시에 날씨 안내
   시작: 2025-01-01 09:00
   종료: (설정 안 함)
   반복: 매일
   
   → 1월 1일부터 무기한 매일 오전 9시 실행
```

#### ✅ 일회성 스케줄 (종료일 불필요)
```
📅 신년 인사 메시지
   시작: 2025-01-01 00:00
   종료: (설정 안 함)
   반복: 반복 없음
   
   → 1월 1일 자정에 한 번만 실행
```

### 필수 여부
- ⚠️ **선택 입력**
- 미설정 시 무기한 반복

---

## 3️⃣ 템플릿 표시 시간 (display_duration_type)

### 설명
- **한 번 실행될 때 화면에 표시되는 시간**
- 전광판에 얼마나 오래 보여줄지 결정

### 옵션

#### 1️⃣ 1분
```
💡 1분간 표시 후 기본 화면으로 돌아갑니다.

예시:
- 오전 9시에 실행 → 9:00~9:01 표시 → 기본 화면 복구
```

#### 2️⃣ 5분 (기본값)
```
💡 5분간 표시 후 기본 화면으로 돌아갑니다.

예시:
- 오전 9시에 실행 → 9:00~9:05 표시 → 기본 화면 복구
```

#### 3️⃣ 10분
```
💡 10분간 표시 후 기본 화면으로 돌아갑니다.

예시:
- 오전 9시에 실행 → 9:00~9:10 표시 → 기본 화면 복구
```

#### 4️⃣ 종일
```
💡 하루 종일 계속 표시됩니다. (다른 우선순위 높은 콘텐츠로 변경 가능)

예시:
- 오전 9시에 실행 → 당일 23:59:59까지 표시
```

#### 5️⃣ 직접입력
```
💡 원하는 시간(분)을 직접 입력합니다. (1~1440분)

예시:
- 30분 입력 → 오전 9시에 실행 → 9:00~9:30 표시 → 기본 화면 복구
```

### 동작 방식
```
display_current_state 테이블에 expires_at 자동 계산:

1분:     activated_at + 1분
5분:     activated_at + 5분
10분:    activated_at + 10분
종일:    당일 23:59:59
직접입력: activated_at + 입력한 분
```

### 필수 여부
- ✅ **필수 선택** (기본값: 5분)

---

## 4️⃣ 반복 설정 (repeat_type)

### 옵션

#### 1️⃣ 반복 없음 (none)
```
한 번만 실행되고 끝남

예시:
- 시작: 2025-01-01 00:00
- 반복: 반복 없음
- 표시 시간: 5분

→ 1월 1일 자정에 한 번 실행 → 5분 표시 → 종료
```

#### 2️⃣ 매일 (daily)
```
매일 시작 시간에 실행

예시:
- 시작: 2025-01-15 09:00
- 종료: 2025-02-15 09:00
- 반복: 매일
- 표시 시간: 10분

→ 1/15 ~ 2/15 동안 매일 오전 9시에 실행
→ 각 실행마다 10분간 표시
```

#### 3️⃣ 매주 (weekly)
```
선택한 요일마다 시작 시간에 실행

예시:
- 시작: 2025-01-15 09:00 (수요일)
- 종료: 2025-02-28 09:00
- 반복: 매주
- 요일: 월, 수, 금 선택
- 표시 시간: 5분

→ 1/15 ~ 2/28 동안 매주 월/수/금 오전 9시에 실행
→ 각 실행마다 5분간 표시
```

## 📌 실전 예시

### 예시 1: 매일 운영시간 안내 (30일 동안)
```yaml
스케줄 이름: 매일 아침 운영시간 안내
템플릿: "공원 운영시간 09:00-21:00"

시작 날짜/시간: 2025-01-01 09:00
스케줄 종료일: ✅ 2025-01-31 09:00
템플릿 표시 시간: 5분
반복 설정: 매일

동작:
- 1월 1일 ~ 1월 31일 동안 매일 오전 9시에 실행
- 각 실행마다 5분간 표시 후 기본 화면으로 복구
- 2월 1일부터는 더 이상 실행되지 않음
```

### 예시 2: 주말 이벤트 안내 (무기한)
```yaml
스케줄 이름: 주말 이벤트 안내
템플릿: "주말 특별 프로그램 안내"

시작 날짜/시간: 2025-01-04 10:00 (토요일)
스케줄 종료일: ❌ 설정 안 함
템플릿 표시 시간: 종일
반복 설정: 매주
선택 요일: 토, 일

동작:
- 매주 토요일/일요일 오전 10시에 실행
- 당일 23:59:59까지 계속 표시
- 무기한 반복 (종료일 없음)
```

### 예시 3: 긴급 공지 (일회성, 1시간 표시)
```yaml
스케줄 이름: 긴급 시설 점검 안내
템플릿: "긴급 안내: 오후 2시 ~ 4시 시설 점검"

시작 날짜/시간: 2025-01-15 14:00
스케줄 종료일: ❌ 설정 안 함 (일회성이므로 불필요)
템플릿 표시 시간: 직접입력 (60분)
반복 설정: 반복 없음

동작:
- 1월 15일 오후 2시에 한 번만 실행
- 60분간 표시 (14:00 ~ 15:00)
- 15:00 이후 기본 화면으로 복구
```

## 🔧 기술 구현 세부사항

### 데이터베이스 필드
```sql
-- schedules 테이블
start_at                  TIMESTAMPTZ  -- 시작 날짜/시간
end_at                    TIMESTAMPTZ  -- 스케줄 종료일 (nullable)
display_duration_type     VARCHAR      -- '1min', '5min', '10min', 'all-day', 'custom'
display_duration_minutes  INTEGER      -- custom 선택 시 분 단위
recurrence_rule          JSONB         -- { freq: 'DAILY' | 'WEEKLY', byweekday: [0,1,2,...] }

-- display_current_state 테이블
activated_at              TIMESTAMPTZ  -- 활성화 시간
expires_at                TIMESTAMPTZ  -- 만료 시간 (nullable)
```

### 실행 로직
```typescript
// 1. 스케줄 실행 시 expires_at 계산
if (displayDurationType === '1min') {
  expiresAt = new Date(now.getTime() + 1 * 60 * 1000).toISOString();
} else if (displayDurationType === '5min') {
  expiresAt = new Date(now.getTime() + 5 * 60 * 1000).toISOString();
} // ... etc

// 2. display_current_state에 삽입
await supabase.from('display_current_state').insert({
  template_id,
  activated_at: new Date().toISOString(),
  expires_at: expiresAt, // ✅ 계산된 만료 시간
});

// 3. 매일 반복 체크
if (recurrence_rule.freq === 'DAILY') {
  const hourMatch = currentHour === startHour;
  const minuteMatch = Math.abs(currentMinute - startMinute) <= 1;
  return hourMatch && minuteMatch;
}

// 4. 매주 반복 체크
if (recurrence_rule.freq === 'WEEKLY') {
  const currentDayOfWeek = currentTime.getDay();
  const daysOfWeek = recurrence_rule.byweekday || [];
  
  if (!daysOfWeek.includes(currentDayOfWeek)) return false;
  
  const hourMatch = currentHour === startHour;
  const minuteMatch = Math.abs(currentMinute - startMinute) <= 1;
  return hourMatch && minuteMatch;
}

// 5. 종료일 체크
if (endDate && currentTime > endDate) {
  return false; // 종료일 지남 - 실행하지 않음
}
```

## 🎯 결론

스케줄 시스템은 **3가지 시간 개념**을 명확히 구분합니다:

1. **시작 날짜/시간**: 언제 처음 실행되나?
2. **스케줄 종료일**: 반복이 언제까지 계속되나? (선택)
3. **템플릿 표시 시간**: 한 번 실행될 때 화면에 얼마나 오래 표시되나?

이 3가지를 올바르게 설정하면 원하는 대로 전광판을 자동 제어할 수 있습니다! ✨
