## 🔧 수정 사항

### 1. ✅ 경기장 아이콘 및 명칭 완전 제거 (최신)

**변경 전:**
```html
<div style="margin-bottom: 20px; padding: 15px;">
  <div style="font-size: 28px; font-weight: bold; color: #ffcc00; margin-bottom: 8px;">
    ${match.stadium}
  </div>
  <div style="font-size: 24px; color: #ffffff;">
    ${clubName}
  </div>
  <div style="font-size: 20px; color: #aaaaaa; margin-top: 8px;">
    ${startTime.getHours()}:${startTime.getMinutes()} ~ ${endTime.getHours()}:${endTime.getMinutes()}
  </div>
</div>
```

**변경 후:**
```html
<div style="margin-bottom: 15px; padding: 12px;">
  <div style="font-size: 28px; color: #ffffff;">
    ${clubName}
  </div>
  <div style="font-size: 24px; color: #aaaaaa; margin-top: 6px;">
    ${startHour}:${startMin} ~ ${endHour}:${endMin} 시
  </div>
</div>
```

**주요 변경점:**
- ❌ 경기장 아이콘(🏟️) 제거
- ❌ 경기장 명칭(${match.stadium}) 제거
- ✅ 팀명을 가장 큰 글씨(28px)로 강조
- ✅ 시간 표시 끝에 "시" 추가로 가독성 향상
- ✅ 패딩/마진 최적화 (20px→15px, 8px→6px)
- ✅ 시간 폰트 크기 향상 (20px→24px)

**이유:**
- 전광판에는 팀명과 시간만 필요 (경기장 정보 불필요)
- 검정 배경에 흰색 팀명으로 최대 가독성 확보
- 불필요한 정보 제거로 정보 밀도 감소 및 시인성 향상

- 이모지 제거로 폰트 호환성 향상
- 전광판 헤더에 딱 맞는 짧은 문구

### 3. ✅ 템플릿 배경색 변경 (청색 → 검정색)

**변경 전:**
```typescript
style_config: {
  backgroundColor: '#1a365d',  // 진한 청색
  textColor: '#ffffff',
  fontSize: '24px',
  fontWeight: 'normal',
  textAlign: 'left',
  fontFamily: 'Arial, sans-serif',
}
```

**변경 후:**
```typescript
style_config: {
  backgroundColor: '#000000',  // 순수 검정
  textColor: '#ffffff',
  fontSize: '24px',
  fontWeight: 'normal',
  textAlign: 'left',
  fontFamily: 'Arial, sans-serif',
}
```

**이유:**
- 전광판 특성상 검정 배경이 가장 높은 명암비 제공
- 흰색(#ffffff) 텍스트와 최고의 대비로 가독성 극대화
- 전광판 LED 수명 연장 효과
