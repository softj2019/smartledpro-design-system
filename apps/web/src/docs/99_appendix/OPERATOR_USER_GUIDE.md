## 1. 시스템 개요

### 1.1 무엇을 할 수 있나요?

✅ **템플릿 생성**: 전광판에 표시할 콘텐츠를 미리 만들어 둡니다  
✅ **일정 등록**: 특정 시간에 자동으로 콘텐츠가 송출되도록 예약합니다  
✅ **순차 반복 송출**: 여러 콘텐츠를 자동으로 순환 표시합니다  
✅ **실시간 확인**: 전광판에 표시되는 내용을 미리보기로 확인합니다

### 1.2 송출 우선순위

전광판은 다음 순서대로 콘텐츠를 표시합니다:

```
1️⃣ 긴급 (EMERGENCY) - 우선순위 999
2️⃣ 공지 (NOTICE) - 우선순위 100~900
3️⃣ 공기질 (AIR_QUALITY) - 우선순위 70
4️⃣ 날씨 (WEATHER) - 우선순위 60
5️⃣ 순차 반복 (ROTATION) - 우선순위 50 (기본 화면)
```

💡 **중요**: 우선순위가 높은 콘텐츠가 송출되면 낮은 우선순위는 자동으로 중단됩니다.

### 1.3 송출 방식

이 시스템에서는 **2가지 방식**으로만 콘텐츠를 송출합니다:

1. **스케줄 (일정 관리)**: 특정 시간에 자동으로 송출
2. **순차 반복 (스튜디오)**: 여러 템플릿을 자동으로 순환 표시

## 3. 템플릿 관리

### 3.1 템플릿이란?

전광판에 표시할 **콘텐츠의 형식**입니다. 한 번 만들어두면 여러 번 재사용할 수 있습니다.

### 3.2 템플릿 생성하기

#### Step 1: 템플릿 관리 메뉴 클릭
메인 화면에서 "템플릿 관리" 버튼을 클릭합니다.

#### Step 2: 새 템플릿 생성
1. **"+ 새 템플릿"** 버튼 클릭
2. 정보 입력:
   - **이름**: 템플릿 구분용 (예: "공원 개장시간 안내")
   - **카테고리**: 
     - `NOTICE` (일반 공지)
     - `EMERGENCY` (긴급)
     - `AIR_QUALITY` (공기질)
     - `WEATHER` (날씨)
   - **본문**: 실제 표시될 내용

#### Step 3: 미리보기 확인
- 우측 미리보기 화면에서 실제 전광판처럼 표시됩니다
- 내용이 잘 보이는지 확인

#### Step 4: 저장
- "저장" 버튼 클릭
- ✅ 템플릿이 목록에 추가됩니다

### 3.3 템플릿 수정/삭제

**수정:**
1. 템플릿 목록에서 수정할 템플릿 클릭
2. 내용 수정 후 "저장" 클릭

**삭제:**
1. 템플릿 우측의 "🗑️ 삭제" 버튼 클릭
2. 확인 메시지에서 "확인" 클릭

⚠️ **주의**: 스케줄이나 순차 반복에 사용 중인 템플릿은 삭제할 수 없습니다.

## 4. 일정 관리 (스케줄)

### 4.1 스케줄이란?

**특정 시간**에 **자동으로** 템플릿을 전광판에 송출하는 기능입니다.

### 4.2 스케줄 생성하기

#### Step 1: 일정 관리 메뉴 클릭
메인 화면에서 "일정 관리" 버튼을 클릭합니다.

#### Step 2: 새 스케줄 등록
1. **"+ 새 일정"** 버튼 클릭
2. 정보 입력:

```
┌─────────────────────────────────┐
│ 📅 새 일정 등록                  │
├─────────────────────────────────┤
│ 이름: ___________________       │
│ 템플릿: [선택 ▼]                │
│ 우선순위: [100~999]             │
│                                 │
│ ⏰ 시작 시간                     │
│   날짜: 2024-12-24              │
│   시간: 09:00                   │
│                                 │
│ ⏹️ 종료 시간                     │
│   날짜: 2024-12-24              │
│   시간: 18:00                   │
│                                 │
│ 🔄 반복 설정                     │
│   [ ] 매일                      │
│   [ ] 매주 (요일 선택)          │
│   [ ] 없음 (1회만)              │
│                                 │
│ [취소]           [등록하기]     │
└─────────────────────────────────┘
```

#### Step 3: 우선순위 설정

| 우선순위 | 용도 | 예시 |
|---------|------|------|
| 900~999 | 긴급/중요 | 행사 취소, 긴급 안내 |
| 500~899 | 일반 공지 | 개장시간, 시설 안내 |
| 100~499 | 정보성 | 날씨, 공기질 |

💡 **팁**: 일반적인 공지는 500~700 정도가 적당합니다.

#### Step 4: 반복 설정

**매일 반복 예시:**
```
✅ 매일 반복
시작: 2024-12-24 09:00
종료: 2024-12-24 18:00

→ 매일 아침 9시~저녁 6시까지 송출
```

**매주 반복 예시:**
```
✅ 매주 반복
요일: 월, 수, 금
시작: 09:00
종료: 12:00

→ 매주 월/수/금 오전 9시~12시까지 송출
```

**1회만 송출:**
```
☑️ 반복 없음
시작: 2024-12-25 14:00
종료: 2024-12-25 15:00

→ 12월 25일 오후 2시~3시에만 1회 송출
```

### 4.3 스케줄 확인 및 관리

**활성 스케줄 보기:**
- 일정 관리 페이지에서 "📊 활성 스케줄" 탭 클릭
- 현재 실행 중이거나 예정된 스케줄 확인

**스케줄 중지:**
1. 중지할 스케줄 우측의 "⏸️ 중지" 버튼 클릭
2. 확인 메시지에서 "확인" 클릭

**스케줄 삭제:**
1. 삭제할 스케줄 우측의 "🗑️ 삭제" 버튼 클릭
2. 확인 메시지에서 "확인" 클릭

## 5. 스튜디오 - 순차 반복 송출 및 전광판 확인

### 5.1 스튜디오란?

**스튜디오**는 다음 2가지 기능을 제공하는 통합 관리 페이지입니다:
1. **순차 반복 송출 설정**: 여러 템플릿을 자동으로 순환 표시
2. **전광판 미리보기**: 현재 송출 중인 화면 확인

---

### 5.2 순차 반복 송출 생성하기

#### 🔄 순차 반복이란?

여러 템플릿을 **자동으로 순서대로 반복** 표시하는 기능입니다.  
다른 스케줄이 없을 때 **기본 화면**으로 사용됩니다.

#### Step 1: 스튜디오 메뉴 클릭
메인 화면에서 **"스튜디오"** 버튼을 클릭합니다.

#### Step 2: 순차 반복 송출 섹션 찾기
페이지를 스크롤하여 **"🔄 순차 반복 송출"** 섹션으로 이동합니다.

#### Step 3: 순차 반복 정보 입력

```
┌─────────────────────────────────┐
│ 🔄 순차 반복 송출 생성            │
├─────────────────────────────────┤
│ 이름: ___________________       │
│                                 │
│ 📝 선택 가능한 템플릿            │
│ (페이지 로드 시 자동으로 표시)   │
│ ┌─────────────────────────┐    │
│ │ [+] 공원 운영시간         │    │
│ │ [+] 주차장 안내           │    │
│ │ [+] 시설 이용 안내        │    │
│ │ [+] 편의시설 위치         │    │
│ └─────────────────────────┘    │
│                                 │
│ ✅ 송출 순서 (선택한 템플릿)     │
│ ┌─────────────────────────┐    │
│ │ 1. 공원 운영시간  [↑↓✕] │    │
│ │ 2. 주차장 안내    [↑↓✕] │    │
│ │ 3. 시설 이용 안내 [↑↓✕] │    │
│ └─────────────────────────┘    │
│                                 │
│ ⏱️ 각 템플릿 표시 시간: [10초 ▼] │
│                                 │
│ 📅 기간 설정                     │
│   시작: 2024-12-24              │
│   종료: 2025-12-24              │
│                                 │
│ [순차 반복 시작]                 │
└─────────────────────────────────┘
```

#### Step 4: 템플릿 선택 및 순서 조정

**템플릿 추가:**
- "선택 가능한 템플릿" 목록에서 **[+]** 버튼 클릭
- 선택한 템플릿이 "송출 순서"에 추가됩니다

**순서 조정:**
- **↑ 위로**: 순서를 앞으로 이동
- **↓ 아래로**: 순서를 뒤로 이동
- **✕ 삭제**: 목록에서 제거

#### Step 5: 표시 시간 설정

| 표시 시간 | 전체 순환 시간 (3개 기준) | 권장 용도 |
|----------|------------------------|----------|
| 5초 | 15초 | 짧은 공지 (1줄 텍스트) |
| 10초 | 30초 | 일반 공지 (2~3줄) |
| 30초 | 1분 30초 | 상세 정보 (여러 항목) |
| 1분 | 3분 | 긴 안내문 |
| 5분 | 15분 | 정적 정보 (변동 없음) |

💡 **권장**: 대부분의 경우 **10초~30초**가 적당합니다.

#### Step 6: 기간 설정
- **시작 날짜**: 순차 반복을 시작할 날짜
- **종료 날짜**: 순차 반복을 종료할 날짜

💡 **팁**: 장기간 운영할 경우 1년 단위로 설정하세요.

#### Step 7: 순차 반복 시작
**"순차 반복 시작"** 버튼을 클릭하면:
1. 순차 반복이 즉시 생성됩니다
2. 다른 스케줄이 없으면 바로 송출이 시작됩니다
3. 우선순위 50으로 자동 설정됩니다

### 5.4 순차 반복과 스케줄의 관계

⭐ **중요 원칙:**

```
우선순위가 높은 스케줄이 시작되면:
→ 순차 반복 자동 중단

스케줄이 종료되면:
→ 순차 반복 자동 재개
```

**실제 동작 예시:**

```
시간  │ 상태
──────┼────────────────────────────────
08:00 │ 순차 반복 중
      │ (공원 안내 → 주차장 → 시설)
      │
09:00 │ 스케줄 시작 ("개장 시간 안내", 우선순위 500)
      │ → 순차 반복 자동 중단
      │ → "개장 시간 안내" 송출
      │
18:00 │ 스케줄 종료
      │ → 순차 반복 자동 재개
      │ → 다시 (공원 안내 → 주차장 → 시설) 순환
      │
22:00 │ 순차 반복 계속 중
```

스튜디오 페이지에서 현재 전광판에 표시되는 내용을 실시간으로 확인할 수 있습니다.

#### Step 1: 전광판 보기 버튼 클릭
스튜디오 페이지 상단의 **"📺 전광판 보기"** 버튼을 클릭합니다.

#### Step 2: 전체 화면 확인

```
┌─────────────────────────────────────┐
```

**2가지 방법:**

### 5.6 현재 송출 상태 확인

스튜디오 페이지 상단에서 현재 송출 중인 콘텐츠 정보를 확인할 수 있습니다:

```
┌─────────────────────────────────────┐
│ 📊 현재 송출 상태                     │
├─────────────────────────────────────┤
│ 송출 중: "공원 운영시간 안내"         │
│ 우선순위: 500 (일반 공지)            │
│ 송출 방식: 스케줄 (ID: 12345)        │
│ 마지막 업데이트: 2분 전               │
└─────────────────────────────────────┘
```

**송출 방식 종류:**
- `스케줄`: 일정 관리에서 등록한 스케줄
- `순차 반복`: 스튜디오에서 설정한 순차 반복
- `STANDBY`: 송출할 콘텐츠 없음

## 6. 디버그 로그 활용

### 6.1 디버그 로그란?

시스템 내부에서 일어나는 모든 동작을 기록한 로그입니다.  
문제가 생겼을 때 원인을 찾는 데 유용합니다.

### 6.2 디버그 로그 보기

#### 방법 1: 전광판 미리보기에서
1. "📺 전광판 보기" 클릭
2. 우측 중앙의 **🐛 버튼** 클릭
3. 우측에서 로그 패널이 슬라이드됩니다

#### 방법 2: 스튜디오 페이지에서
1. 우측 중앙의 **🐛 플로팅 버튼** 클릭
2. 로그 패널 열림

### 6.3 로그 필터링

```
┌─────────────────────────────────────┐
│ 🐛 디버그 로그                        │
├─────────────────────────────────────┤
│ [전체] [에러] [경고] [정보] [성공]    │
│                                     │
│ 🔍 검색: _____________ [지우기]      │
│                                     │
│ ✅ [12:34:01] 템플릿 로드 성공        │
│ ℹ️ [12:34:05] 스케줄 확인 중         │
│ ⚠️ [12:34:10] 네트워크 지연          │
│ ❌ [12:34:15] API 호출 실패          │
│                                     │
│ [📋 JSON 복사] [🗑️ 로그 지우기]      │
└─────────────────────────────────────┘
```

**필터 버튼:**
- **전체**: 모든 로그 표시
- **에러**: ❌ 오류만 표시
- **경고**: ⚠️ 경고만 표시
- **정보**: ℹ️ 정보만 표시
- **성공**: ✅ 성공만 표시

**검색:**
- 검색창에 키워드 입력 (예: "템플릿", "스케줄")
- 해당 키워드가 포함된 로그만 표시

### 6.4 로그 복사 및 공유

문제가 발생했을 때 관리자에게 로그를 전달하는 방법:

1. 디버그 로그 패널 열기
2. "📋 JSON 복사" 버튼 클릭
3. 이메일이나 메신저에 붙여넣기

## 7. 문제 해결

### 7.1 템플릿이 송출되지 않아요

#### 체크리스트:
- [ ] 템플릿이 제대로 저장되었나요?
- [ ] 스케줄이 활성화되어 있나요?
- [ ] 스케줄 시작 시간이 현재 시간보다 이전인가요?
- [ ] 더 높은 우선순위의 다른 스케줄이 실행 중인가요?

#### 해결 방법:
1. **일정 관리** 페이지로 이동
2. **활성 스케줄** 탭에서 현재 실행 중인 스케줄 확인
3. 우선순위가 높은 스케줄이 있으면 그것이 먼저 송출됨

### 7.2 순차 반복이 작동하지 않아요

#### 체크리스트:
- [ ] 순차 반복이 생성되었나요?
- [ ] 최소 2개 이상의 템플릿이 선택되었나요?
- [ ] 시작/종료 날짜가 현재 날짜를 포함하나요?
- [ ] 다른 스케줄이 실행 중이지 않나요?

#### 해결 방법:
1. **스튜디오** 페이지로 이동
2. **현재 송출 상태** 확인
3. 스케줄이 실행 중이면 스케줄이 우선 송출됨 (정상)
4. 스케줄 종료 후 자동으로 순차 반복이 재개됨

### 7.3 스케줄이 시간에 맞춰 송출되지 않아요

#### 원인:
- 서버 시간과 로컬 시간 차이
- 반복 설정 오류
- 우선순위 충돌

#### 해결 방법:
1. **디버그 로그** 열기
2. "스케줄" 키워드로 검색
3. 에러 메시지 확인
4. 필요 시 스케줄 삭제 후 재생성

### 7.4 전광판 화면이 멈춰있어요

#### 체크리스트:
- [ ] 전광판 전원이 켜져 있나요?
- [ ] 네트워크 연결이 정상인가요?
- [ ] 송출할 콘텐츠가 있나요?

#### 해결 방법:
1. **전광판 보기**에서 현재 상태 확인
2. "STANDBY" 표시가 보이면 → 순차 반복 등록 필요
3. 빈 화면이면 → 전광판 전원 및 네트워크 확인

### 7.5 템플릿 목록이 표시되지 않아요

#### 증상:
스튜디오 > 순차 반복 송출에서 "선택 가능한 템플릿" 목록이 비어있음

#### 해결 방법:
1. 페이지를 **새로고침** (F5 키)
2. 템플릿 관리에서 최소 1개 이상의 템플릿이 생성되어 있는지 확인
3. 디버그 로그에서 "템플릿" 키워드로 검색하여 에러 확인

## 8. 자주 묻는 질문 (FAQ)

### Q1. 여러 템플릿을 동시에 송출할 수 있나요?
**A**: 아니요. 전광판은 한 번에 하나의 콘텐츠만 표시합니다.  
우선순위가 높은 콘텐츠가 먼저 송출되고, 종료되면 다음 우선순위가 송출됩니다.

### Q2. 순차 반복은 언제 사용하나요?
**A**: 기본 화면으로 사용합니다.  
예약된 스케줄이 없을 때 자동으로 여러 안내사항을 순환 표시합니다.

### Q3. 템플릿을 수정하면 이미 등록된 스케줄에도 반영되나요?
**A**: 네, 즉시 반영됩니다.  
템플릿을 수정하면 해당 템플릿을 사용하는 모든 스케줄에 자동으로 적용됩니다.

### Q4. 스케줄을 삭제하면 어떻게 되나요?
**A**: 해당 스케줄의 송출이 즉시 중단됩니다.  
다음 우선순위의 콘텐츠(또는 순차 반복)가 송출됩니다.

### Q5. 전광판이 꺼져 있어도 스케줄은 작동하나요?
**A**: 네, 시스템은 계속 작동합니다.  
전광판을 다시 켜면 현재 송출되어야 할 콘텐츠가 자동으로 표시됩니다.

### Q6. 긴급 공지를 빠르게 송출하려면 어떻게 하나요?
**A**: 일정 관리에서 새 스케줄을 만들고 우선순위를 999로 설정하세요.  
시작 시간을 현재 시간으로 하면 등록 즉시 자동으로 송출됩니다.

### Q7. 스튜디오 페이지에서 무엇을 할 수 있나요?
**A**: 스튜디오에서는 2가지를 할 수 있습니다:
1. 순차 반복 송출 생성 및 관리
2. 전광판 미리보기 (현재 송출 화면 확인)
